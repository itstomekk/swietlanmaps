# Updating

1. In the private pipeline project, add or re-read maps, then run `build_web.py` and `export_site.py`. The export writes `docs/index.html` and `docs/img/` here and removes images that are no longer used.
2. Open `docs/index.html` locally and check a few words, a county click and the index view.
3. Commit `docs/` and push to `main`. GitHub Pages republishes in a minute or two.
4. Check the live site: <https://itstomekk.github.io/swietlanmaps/>.
